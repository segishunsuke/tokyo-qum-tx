### 1995年の従業者数について

論文では，1995年の従業者数に事業所・企業統計調査（1996年）の地域メッシュ統計（公益財団法人統計情報研究開発センター）を用いています（`jobs/1995/generate.py`）．このデータは公開されていないため，`model/input/input_data.xlsx` の1995年の従業者数（シート `lam_M` の1995年の列と，シート `parameters` の1995年の総従業者数 $\bar{L}$）には，公開データから推計した代替データを収録しています．代替データを用いた推定・シミュレーションの結果は，論文の値とは一致しません．

代替データは `jobs/1995/generate_dummy_1995.py` により，以下の公開データから作成しました．

1. 事業所・企業統計調査（2001年）4次メッシュ（500m）統計「全産業事業所数及び従業者総数」（e-Stat，世界測地系）
2. 事業所・企業統計調査（1996年）の市区町村別従業者数（e-Stat，都道府県編 表003）
3. 1995年10月1日時点の行政区域（国土数値情報 N03）

500mメッシュと行政区域を重ね，重なった部分ごとに，2001年の従業者数の合計が1996年の市区町村別従業者数に一致するように市区町村別の倍率を掛けて補正した上で，計画基本ゾーンに面積按分しました．複数の行政区域にまたがるメッシュには，部分ごとに異なる倍率が掛かります．実データによる値と比べると，ゾーン別従業者数の相関係数は0.988，対数の相関係数は0.987，ゾーン計の差は+0.6%です．

元の地域メッシュ統計を入手した場合は，`jobs/1995/generate.py` でゾーン別の従業者数を作成し，`input_data.xlsx` の上記2か所を置き換えれば，論文の結果を再現できます．

## `network/07b_最短経路探索/`：一般化費用の計算と推定

交通ネットワーク（道路・高速道路・路線バス・高速バス・鉄道，1995年・2015年・2015年 TX なし）とゾーン代表点は，作成済みのデータを Zenodo で公開しています：DOI: [10.5281/zenodo.23879232](https://doi.org/10.5281/zenodo.23879232)．このデータを `07b_最短経路探索/input/` に置けば，以下を再現できます．ネットワークの作成に用いた元データは，OpenStreetMap，道路交通センサス（旅行速度），国土数値情報（高速道路時系列 N06，バスルート N07，バス停留所 P11，高速バス停留所 P36，鉄道時系列 N05）です．

| ファイル | 内容 |
|---|---|
| `search_passenger_separated.py`，`input/settings_*.csv` | ゾーン間の最短経路探索（自動車・公共交通，年次別，TX なし） |
| `remove_tx.py` | 2015年の鉄道ネットワークから TX を除いたネットワークの作成 |
| `make_pt_od.py`，`tx_station_riders.py` | 通勤 OD の公共交通ネットワークへの配分と TX 駅別乗降客数（論文 5. (1) a)） |
| `モード分担・重力モデル推定/` | モード分担モデル，通勤重力モデル，合成一般化費用 $\tau_{ij}$ と $\tau_{ii}$ の計算（論文 4. (6)〜(8)）．パーソントリップ調査の公開集計値を使用 |
