# 居住者数・従業者数の集計（修正版）

TX論文の修正（2026年10月）に伴い，集計コードを点検した結果．

## 分析に用いるファイル

| 年次 | 変数 | ファイル |
|---|---|---|
| 1995 | 居住者 | `residence/1995/population_1995_apportioned.csv`（変更なし） |
| 2015 | 居住者 | `residence/2015/population_2015_apportioned.csv`（変更なし） |
| 1995 | 従業者 | `jobs/1995/employee_1995_apportioned_corrected.csv`（**修正**） |

## 変更点

### 1. 1995年従業者：測地系の修正（`jobs/1995/generate.py`，元のコードは `generate_original.py`）

CSIS提供の1996年事業所・企業統計調査の地域メッシュは日本測地系（旧東京測地系）で定義されている．
元のコードは世界測地系（EPSG:4612）として扱っていたため，東京付近で約400m ずれた位置で按分されていた．
EPSG:4301 として扱うよう修正した．列は全産業の従業者総数（F3，国・地方公共団体を含む）のまま．

根拠：`check_geodetic_datum.py` で，メッシュを両方の測地系で配置し，新しい年次（世界測地系）のデータとの
空間的な対応（log 相関）を比較した（1次メッシュ 5339 / 5340 / 5439）．

| データ | 世界測地系として配置 | 日本測地系として配置 | 判定 |
|---|---|---|---|
| 1995年国勢調査 500m（e-Stat） | 0.92 / 0.83 / 0.83 | 0.74 / 0.61 / 0.60 | 世界測地系 |
| 1996年事業所統計 1km（CSIS） | 0.85 / 0.67 / 0.73 | 0.92 / 0.81 / 0.83 | 日本測地系 |
| 2014年経済センサス‐基礎調査 500m | 0.97（5339） | 0.79（5339） | 世界測地系 |

### 2. 2015年従業者：2014年経済センサス‐基礎調査に変更（`jobs/2014/generate.py`）

2016年経済センサス‐活動調査は民営事業所のみが対象で，国・地方公共団体の事業所（官公庁，公立の学校・病院等）を含まない．
1996年事業所統計（全産業）とパーソントリップ調査の通勤トリップはこれらを含むため，
国・地方公共団体の事業所を含む2014年経済センサス‐基礎調査の全産業従業者数（T000842002，世界測地系500mメッシュ）に変更した．
（確認：霞が関付近のメッシュ 533946003 で，2014年基礎調査 31,390 人，2016年活動調査 15,748 人）

### 影響

| | 元の値 | 修正後 |
|---|---|---|
| 総従業者数 1995年 | 17,700,320.2 | 17,799,061.1 |
| 総従業者数 2015年 | 17,770,581.6 | 19,075,165.2 |

ゾーン別シェアが 20% 以上変化したゾーン数：1995年 107（50%以上 13），2015年 10．

## 点検して問題がなかったもの

- メッシュコード → 緯度経度の計算（1km・500m・250m）：JIS の定義どおり
- 面積按分の処理
- 列の選択：人口総数（T000752001, T000876001），1996年 F3 = 全産業 従業者総数
- 2015年250mメッシュの秘匿処理：各行の人口総数はそのメッシュ自身の値で，全行の合計で二重計上なし
- 1995年国勢調査500mメッシュ（e-Stat）の測地系

## 残る相違（参考）

1996年事業所統計には農林漁業が含まれないが，2014年基礎調査には農林漁業（個人経営を除く）が含まれる．影響は小さい．
